# 研修生Issue運用

研修生ごとに1件のIssueを作成し、技術研修課題からGate5までを同じIssueで管理します。完了時にIssueをCloseします。

## 初回登録

1. Issuesから「研修生の進捗管理」を選択します。
2. 研修生の氏名を入力し、必要に応じて管理用の識別子も併記します。
3. メールアドレス、SlackユーザーID・プロフィールURLなど、管理に必要な連絡情報を入力します。
4. 担当者、現在フェーズ、進捗状況、次の提出期限、次のアクションを入力します。
5. Issueを作成し、`研修生`ラベルを付与します。

## 更新

フェーズ、進捗状況、提出期限、次のアクションはIssue本文を更新します。提出確認・レビュー・判定・連絡などの時系列の記録は、Issueコメントに次の形式で残します。

```text
YYYY/MM/DD | 実施者 | 内容 | 根拠URL（ある場合）
```

Gateを通過したら、本文の該当チェック項目を完了にします。要修正の場合は、進捗状況を`要修正`にし、次のアクションに修正内容と期限を明記します。

## 一覧確認

GitHub Issuesで`is:issue is:open label:研修生`を保存検索にすると、進行中の研修生を一覧できます。期限超過の自動集計はGitHub Issuesだけでは行わないため、期限ごとの確認は担当者が定期的に行います。

## 情報管理

このリポジトリはプライベートかつアクセス制御された状態を前提とします。研修生管理に必要な氏名、メールアドレス、電話番号、Slack識別情報、業務連絡、非公開URLなどはIssueに記録できます。個人情報を匿名化・省略することは運用上の必須要件としません。

ただし、パスワード、アクセストークン、APIキー、秘密鍵、セッションCookieなど、認証を直接可能にする秘密情報はIssueに保存しません。

リポジトリの公開範囲またはアクセス権を変更する場合は、保存済みの個人情報・非公開情報を事前に確認します。
