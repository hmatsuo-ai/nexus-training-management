# 研修生Issue運用

研修生ごとに1件のIssueを作成し、技術研修課題からGate5までを同じIssueで管理します。完了時にIssueをCloseします。

## 初回登録

1. Issuesから「研修生の進捗管理」を選択します。
2. 氏名ではなく管理用の識別子を入力します。
3. 担当者、現在フェーズ、進捗状況、次の提出期限、次のアクションを入力します。
4. Issueを作成し、`研修生`ラベルを付与します。

## 更新

フェーズ、進捗状況、提出期限、次のアクションはIssue本文を更新します。提出確認・レビュー・判定・連絡などの時系列の記録は、Issueコメントに次の形式で残します。

```text
YYYY/MM/DD | 実施者 | 内容 | 根拠URL（ある場合）
```

Gateを通過したら、本文の該当チェック項目を完了にします。要修正の場合は、進捗状況を`要修正`にし、次のアクションに修正内容と期限を明記します。

## 一覧確認

GitHub Issuesで`is:issue is:open label:研修生`を保存検索にすると、進行中の研修生を一覧できます。期限超過の自動集計はGitHub Issuesだけでは行わないため、期限ごとの確認は担当者が定期的に行います。

## 取り扱わない情報

リポジトリの公開範囲にかかわらず、氏名、メールアドレス、電話番号、Slack/Gmail本文、認証情報、非公開URLはIssueに保存しません。必要な原本や連絡履歴は、アクセス制御された別のシステムに保存します。
